# NVDA Explore

**NVIDIA stock analysis -- technical indicators, earnings impact modeling, and price action research.**

![Status](https://img.shields.io/badge/status-maintained-blue)
![Python](https://img.shields.io/badge/python-3.x-blue)

## What It Does

Research repository for analyzing NVIDIA (NVDA) stock behavior. Explores technical indicators, models the impact of quarterly earnings on price action, and investigates patterns in NVDA's historical price data to inform trading decisions.

## Features

- **Technical indicator analysis** -- moving averages, RSI, MACD, and custom indicators applied to NVDA
- **Earnings impact modeling** -- quantifies how quarterly earnings reports affect price movement
- **Price action research** -- historical pattern analysis and trend identification
- **Data-driven approach** -- analysis backed by historical market data
